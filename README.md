# Entretien préventif

App web hors-ligne (PWA) pour faire les tournées d'entretien préventif d'écoles sur un cellulaire : tâches horodatées, journal, suivis, photos, rapports, synchronisation optionnelle vers Google Sheets.

Les données restent sur l'appareil (IndexedDB) ; ce dépôt ne contient que le code.
